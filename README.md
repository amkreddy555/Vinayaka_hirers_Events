## 📖 About
At your service since 1989, Vinayaka Events & Hirers stands as a pillar of excellence in event management in Nellore, A.P., India. For over three decades, we have been delivering unparalleled event experiences, invoking blessings from the Almighty and ensuring every special moment is unforgettable.

## 🚀 Key Features
- **Premium Design**: A high-end, glassmorphic aesthetic tailored for elegance and brand consistency.
- **Mobile Optimized**: Fully responsive layout with specific optimizations for mobile loaders, compact grids, and space-saving headers.
- **Dynamic Media**: Optimized background video loading for smooth transitions and reduced loading times.
- **Scroll Spy Navigation**: Smooth scrolling with an intelligent navigation bar that highlights current sections (Services, Gallery, About, Contact).
- **Interactive Elements**:
  - Floating WhatsApp button for instant inquiries.
  - Background music toggle for an immersive experience.
  - Interactive service cards and location markers.

## 🛠️ Technology Stack
- **Structure**: HTML5 (Semantic elements)
- **Styling**: Vanilla CSS3 (Custom properties, Media queries, Animations)
- **Interactivity**: Vanilla JavaScript (Intersection Observer API, DOM manipulation)
- **Icons**: Font Awesome, Lucide Icons
